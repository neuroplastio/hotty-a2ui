# 2026-10-12.1 — KIT-17c: HottyFilePicker

The phase-1 leg of KIT-17: bubbles' and huh's filepicker, walking a directory
listing to pick a file. Story `hotty/filepicker`: a Card containing
`HottyFilePicker` over a granted root `project`.

**The filesystem limit (L10) and grant design.** A file picker needs
filesystem access, which A2UI/agents must not have (limit L10).
- Roots are program-granted `io/fs.FS` values, not OS paths. Stored in
  `view.State.Roots map[string]fs.FS`; the program sets them via
  `Controller.Grant(name, fsys)`. This works in WebAssembly (the storybook
  grants a fixture `fstest.MapFS`) and is testable without OS dependencies.
- The renderer reads the filesystem on each build; the agent only names a
  root and a relative path. The picked path reaches the agent only through the
  bound `selected` property when picked.
- Clamped paths: directory paths are relative to the root; any `.` or `..`
  segments that would leave the root are clamped inside it (`cleanFile`).
- Props: `root` (required string), `path` (bound DynamicString, current dir),
  `selected` (bound DynamicString, picked file path), `filter` (DynamicString,
  case-insensitive substring), `onPick` (Action when a file is picked),
  `onChange` (Action when directory changes), `height` (number of rows),
  `emptyText` (DynamicString placeholder).

**The reference.** bubbles' `filepicker` (`charm.land/bubbles/v2/filepicker`,
wrapped in `ref/gaps.go` as `filepickerRef`, `make shot NAME=filepicker`):
shows directories first with a trailing `/`, files with formatted size
columns (B, K, M, G, T), keyboard navigation with arrows and vim keys, and
selection.

**The catalog** (profile §6.31, instruction 31). Schema added to
`catalog/hotty/catalog.json`, validated in `catalog/hotty/hotty_test.go`.

**The view** (`view/filepicker.go`): Kind `FilePicker`, `FileEntry`, `FilePick`,
`FileDir`, `Files`, `State.Roots` and `State.File`. `Controller.Grant`,
`ClickFile`, `FileKey`, `fileGo`, `fileOpen`, `fileUp`. Key navigation covers
arrows, PageUp/PageDown, Home/End, g/G, Enter/l, and Escape/Backspace/h.

**Cells** (`rendition/cells/filepicker.go`): directory path on title row
reversed in `accent` followed by a blank row, then entries indented 2
columns. Directories first with trailing `/`, file sizes right-aligned in
`muted`. The selected entry's first 2 columns are `│ `, in `accent` with its
name while focused, bold in `muted` otherwise. Windowed at `height`.

**Host / HTML** (`rendition/html/filepicker.go`): `div.k-filepicker`
(`role=listbox`), title `div.k-file-title`, entries `div.k-file-item`
(`role=option`) with `.k-sel` and `aria-selected`, directory with trailing `/`,
size in `span.k-file-size`; filler gaps to maintain height; `data-keys` gives
navigation keys to the program. In page mode (`rendition/html/page.go`),
all entries render unwindowed.

**Text** (`rendition/text/text.go`): directory shown, `/`, then every entry,
directory with trailing `/`, `> ` for highlighted entry, and file size in
bytes; error or empty text if applicable.

**Story and vectors:**
- Story `story/stories/hotty/filepicker.json` with fixture filesystem
  `story/fixture.go` (`FixtureFS`) granted as `"project"`.
- Vectors `vectors/keys.yaml`: arrows navigation, entering directory,
  picking file (`go.mod`), navigating up with Escape.
