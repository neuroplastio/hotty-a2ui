# 2026-10-10.3 — HottyIcon

The second item of the storybook revamp (2026-10-10): its nav and tabs
need icons the 59 don't have (a tree, a terminal, code). gov R-4 had put
`HottyIcon` off until a story needed a name beyond the 59, and the
storybook now does. The design is R-4's, but with the program's own
icons instead of the whole pack.

**The catalog** (profile §6.15, instruction 15): `HottyIcon` has `name`,
a Material Symbols name in snake_case (`^[a-z0-9]+(_[a-z0-9]+)*$`), or
`{svgPath, strokeWidth}`, or a binding; and `weight`. A HottyTree node's
`icon` takes the same names.

**Package `icons`:**
- `Named(name)`: a name a program registered (`Register`, from init),
  else one of the 59 by Material's name. `material` in `basic.go` maps
  those: snake_case, A2UI's renames (`play_arrow`, `fast_rewind`), and
  the font's main name for a second name (`credit_card` for `payment`).
  `favoriteOff` and `starOff` have none: Material's `favorite` and `star`
  are filled.
- `Icon.Stroke`: a path stroked that wide, not filled. A host draws it
  with round caps and joins, as Lucide's are.
- `Glyph` takes Material's names of the 59 too.

**The generator:** `cmd/iconsgen -set dir` writes `dir/icons_gen.go`, an
init in dir's package that registers the names `dir/icons.txt` lists,
Sharp and filled, from the same pinned package. It refuses a name of the
59 (`HottyIcon` has it already) and one that isn't Material's form.
`make icons` writes the storybook's: 8 icons, under 2 KB of paths. A test
in `storybook` fails when `icons.txt` names one `icons_gen.go` lacks.

**Why a set, not the pack:** the whole style is 4,033 icons, 347 KB
gzipped. The site's storybook module would grow by a quarter for the
dozen it draws. R-4's `icons/materialsymbols/`, for a program that takes
any name, can still come; until then a name a program hasn't registered
draws `◇`, as an unknown name always has.

**Stories:** `hotty/icon` shows five registered names, `account_circle`
(one of the 59 by Material's name), a stroked path, and an unknown name.
`hotty/tree`'s files have `description` icons now.

**Checked:** `make check`; `hotty render` of both stories in the
terminal theme: crisp shapes in the text's colour, the stroked ring
round-capped, `◇` for the unknown name.
