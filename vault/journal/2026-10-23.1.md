# 2026-10-23.1 — KIT-HIDE: hidden, by the data model

plx's settings page shows a Reset button only while a setting differs
from its default, and a section only where it applies. It reached for
`accessibility.hidden`, which hid the element in cells and not on a host,
and settled for templates of `[{}]` or `[]`.

A2UI v1.0 has no `visible`. Its `accessibility.hidden` is ARIA's
`aria-hidden`: kept from a screen reader, still shown. Cells had read it
as "takes no room", which no other renderer does.

**Now `io_neuroplast_hotty.hidden`,** a DynamicBoolean on any component
(`{"@path": "/reset/none"}`): while true, the component and what it holds
show nothing, take no room and no Tab stop, in all three renditions. On a
host it is the class `k-hidden` (`display: none`), so showing it again is
one attribute's delta. `accessibility.hidden` is drawn in cells again,
and aria-hidden on a host.

**The keyboard moves on.** A Reset button that hides itself once pressed
had the keyboard, and kept it while hidden: the next Enter would press it
again. Rebuild now hands the keyboard to the next element that takes it,
else the last before it (leaveHidden), and drops it only with neither,
where the next key would go to the terminal's program. Focusables,
placeOf and autofocus pass over hidden elements alike (walkHidden), so a
link in place's Tab count no longer counts them either.

**Checked:** the gate; TestHidden in cells (no room, no Tab stop, the
keyboard on to Next, the a11y-hidden icon drawn) and on a host (k-hidden
and its delta, aria-hidden alone).
