# 2026-10-17.3 — HOTTY 0.4: keys are myelin key names

The kit moves to HOTTY 0.4 (hotty a57d9b8, SPEC §10.4), on hotty-go's
local branch `hotty-0.4` (3fc00e1) through `replace` directives in go.mod,
which go when hotty-go 0.4 is released.

What changed:
- **Every key the kit writes or compares is a myelin key name**: `ctrl+s`,
  `arrow_down`, `page_up`, `escape`, `space`, `shift+tab`, `alt+arrow_up`.
  The views' key handlers (`view`), cells' `Key`, the HTML rendition's
  `data-keys` constants, the storybook's and the review app's keys, the
  catalog's `key` pattern and instructions, the stories, the vectors
  (`vectors/keys.yaml`) and `docs/profile.md`.
- **A capital is `shift+` its letter**: `G` is `shift+g` where Shift is
  meant (tables, lists, trees, diffs, file pickers, scroll views, and the
  `=scroll-end` and `=program` bindings), since a host reads `G` as `g`.
- **A typed character is `hotty.KeyText`**: a list's filter, a select's and
  a cycle's type-ahead, and a field's insert (`shift+a` types `A`).
- **`mod` in a HottyShortcut's key** is read with the controller's
  Platform (`Controller.HasShortcut`, `Shortcut`; `SameKey` reads with the
  zero one). `Platform.Mod` is `"ctrl"` or `"super"`; the key hints write
  `mod`'s keys as the platform's, `super` last.
- The vectors' `type:` steps press a capital as `shift+` its letter.
