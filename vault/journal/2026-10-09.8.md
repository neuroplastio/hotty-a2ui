# 2026-10-09.8 — KIT-02h and KIT-03h: motion on a host

The maintainer saw hotty/progress's Indexing bar stand still on a HOTTY
host. Both phase-2 legs are taken ahead of the rest of phase 2: the fix
is small, and it shares the cells clock.

**One clock.** The view now holds the clock's arithmetic, so both
renditions ask it the same question:
- `SpinnerSet.Frame(t)` is frame ⌊t / interval⌋ mod the frames.
- `ProgressStep(t)` is step ⌊t / 100 ms⌋ mod 50 of a five-second sweep.
  Cells starts the segment at column ⌊k × (bar + segment) / 50⌋ −
  segment. The old formula took a step a column, so the sweep's length
  depended on the bar's width. A host starts it at k × 125% / 50 − 25%
  of the track.

So cells and HTML side by side show the same frame. The sweep takes five
seconds at any width.

**HTML:**
- `html.Rendition` has `Clock` (time.Now by default; tests stop it) and
  `Animating`, as cells does. A Doc or an Update notes the shortest
  interval it showed.
- An indeterminate Progress carries `style="--k-at: X%"`. The fill's CSS
  is `left: var(--k-at)`, and the track's `overflow: hidden` clips the
  ends. A tick is one `attr` delta on the Progress, and its children
  stay as they are.
- A Spinner's frame has an id of its own (`<id>~f`), so a tick is one
  `text` delta. An emoji frame is a `k-emoji` span, so its tick is a
  small `inner` delta on the frame.
- `Book.Tick` takes the shortest interval across the cells panes and the
  HOTTY surfaces the last View placed. `Book.shown` holds the latter. It
  reads them at Tick time, after the session's Layout has sent any new
  document.

**Checked:**
- An html test steps a stopped clock. Each tick sends exactly the attr
  delta and the text delta, and the documents match a fresh Doc. Once the
  bar has a value and the spinner stops, `Animating` is 0 and a tick
  sends nothing.
- A storybook test watches the Line spinner's frame on hottytest's host
  for a second. It fails without the HOTTY surfaces in `Tick`.
- `hotty render` at three positions (−12.5%, 40%, 90%): Blitz honours
  the variable and clips at the track.
- Live in the storybook pane on hottyterm.
