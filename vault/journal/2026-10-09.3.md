# 2026-10-09.3 — KIT-REF: reference shots

Phase 1 holds each component against Bubble Tea's. This leg builds the
tooling for that.

- **`ref/`** is a Go module of its own, so bubbles, huh and lipgloss stay out
  of the kit's go.mod.
  - `bin/ref NAME` runs one reference on the whole screen.
  - `bin/ref -list` names each reference with the story it is held against.
  - There are references for form (huh: Input, Select and Confirm),
    textarea, progress, spinner, table and list, taken from the bubbles
    examples.
  - `make check` tidies, vets and builds it.
- **`storybook -bare STORY`** shows a story's surfaces alone, in cells, on
  the whole screen, with no list, pickers or panel.
  - Tab gives the surface the keyboard, Escape takes it back, and q or
    Control+C quits.
  - It's also a quick way to try a component's keys.
- **`make shot NAME=form`** (`scripts/ref-shot.sh`) runs each side in VHS in
  the same 80×24 terminal, with the same font and theme. It writes one
  picture, `.shots/NAME.png`, with Bubble Tea's side on the left and the
  kit's on the right.
  - Keys sent first put both sides in the same state: `KIT_KEYS` (default
    Tab) and `REF_KEYS`.

The first shot, `make shot NAME=form`, shows what KIT-LOOK has to close.
